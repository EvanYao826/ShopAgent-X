## 2. 本地完整部署

### 2.1 环境要求

| 环境 | 版本 | 检查命令 | 说明 |
|------|------|---------|------|
| JDK | 17+ | `java -version` | Spring Boot 3.x 要求 |
| Python | 3.10+ | `python --version` | LangChain / FAISS 要求 |
| Docker | 20+ | `docker --version` | 运行 MySQL + Redis |
| Maven | 3.8+ | `mvn -version` | Java 构建工具 |
| Node.js | 18+（可选） | `node -version` | 仅管理端需要 |
| Android Studio | Hedgehog+（可选） | - | 仅编译 App 需要 |

### 2.2 部署步骤

#### Step 1：启动基础服务（MySQL + Redis）

```bash
cd ShopAgent-X
docker-compose up -d
```

验证容器正常运行：
```bash
docker ps
# 应看到两个容器：
#   shopagent-mysql   (端口 3306)
#   shopagent-redis   (端口 6379)
```

MySQL 启动时自动执行 `backend/sql/init.sql`，创建 25 张表和 100 条商品示例数据。

#### Step 2：启动 Python AI 服务（端口 8000）

```bash
cd backend/python-service

# 创建并激活虚拟环境
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS/Linux

# 安装依赖（国内镜像加速）
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 配置环境变量
cp .env.example .env
```

编辑 `.env`，填入以下必填配置：

```env
# 豆包大模型 API Key（必填）
DOUBAO_API_KEY=你的豆包API密钥
DOUBAO_BASE_URL=https://ark.cn-beijing.volces.com/api/v3/
DOUBAO_MODEL=你的模型端点ID
```

启动服务：
```bash
python main.py
```

验证：控制台显示 `Uvicorn running on http://127.0.0.1:8000`，浏览器访问 `http://localhost:8000/docs` 可看到 Swagger API 文档。

#### Step 3：启动 Java 后端（端口 8888）

```bash
cd backend
mvn spring-boot:run
```

验证：控制台显示 `Started ShopAgentXApplication in X seconds`。

#### Step 4：启动 React 管理端（可选，端口 3000）

```bash
cd backend/frontend
npm install
npm run dev
```

验证：浏览器打开 `http://localhost:3000`，可看到管理端登录页面。

#### Step 5：编译 Android 客户端（可选）

1. Android Studio 打开 `android/` 目录
2. 等待 Gradle 同步完成
3. 连接 Android 设备或启动模拟器
4. 点击 Run 编译安装

> **模拟器注意：** `BASE_URL` 默认为 `http://60.17.179.9:8888/`，本地测试时需改为 `http://10.0.2.2:8888/`（模拟器访问宿主机 localhost 的地址）。真机测试时改为电脑的局域网 IP。
>
> 修改位置：`android/app/build.gradle.kts` 第 23 行

## 3. 快速体验场景

以下场景覆盖了项目的核心功能和加分项，建议按顺序体验。

### 场景 1：基础商品推荐（最小闭环）

**App 对话页输入：**
```
推荐一款适合油皮的洗面奶
```

**预期效果：**
- AI 返回个性化推荐话术（如"为你推荐几款适合油皮的洗面奶..."）
- 底部展示 3-5 个商品卡片（含图片、标题、价格、评分）
- 点击商品卡片可跳转商品详情页

### 场景 2：多轮对话 + 渐进式需求收敛

```
第 1 轮：推荐跑鞋
第 2 轮：要轻量的
第 3 轮：不要超过五百
```

**预期效果：**
- 第 1 轮返回 5 款跑鞋
- 第 2 轮从已有结果中筛选轻量款（不是重新搜索）
- 第 3 轮进一步按价格过滤，推荐话术体现上下文理解

### 场景 3：反选排除

```
推荐防晒霜，但不要含酒精的
```

**预期效果：**
- 返回的防晒霜商品都不含酒精成分
- 推荐话术中提到排除逻辑

### 场景 4：对话式购物车管理

```
第 1 步：推荐面膜
第 2 步：把这个加到购物车
第 3 步：看看我的购物车
第 4 步：删除第一个
```

**预期效果：**
- "加购物车"后显示确认卡片，点击确认完成加购
- "看看购物车"返回当前购物车列表
- "删除第一个"显示删除确认卡片

### 场景 5：拍照识图

1. 点击输入框左侧的 `+` 按钮
2. 选择"拍照"或"从相册选择"
3. 拍摄或选择一张商品图片

**预期效果：**
- AI 识别图片中的商品特征（如"白色运动鞋"）
- 返回相似商品推荐

### 场景 6：语音输入

1. 点击输入框左侧的麦克风图标，切换到语音模式
2. 点击"点击说话"，说出需求（如"推荐一款面霜"）
3. 录音完成后自动识别，文字填入输入框
4. 确认无误后点击发送

**预期效果：**
- 语音被准确转为文字
- 文字填入输入框供确认后发送

### 场景 7：闲聊对话

```
你好，今天天气怎么样？
```

**预期效果：**
- AI 进入闲聊模式，不推荐商品
- 自然对话回复

### 场景 8：知识问答

```
敏感肌和干性皮肤有什么区别？
```

**预期效果：**
- AI 基于知识库回答专业问题
- 回答内容有据可查

## 5. 常见问题

### Q1：Python 服务启动失败

**常见原因及解决：**
- `.env` 未配置 `DOUBAO_API_KEY` → 填入有效的豆包 API Key
- 虚拟环境未激活 → 确保执行了 `venv\Scripts\activate`
- 依赖安装失败 → 使用国内镜像：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`
- FAISS 安装报错 → 确认 Python 版本为 3.10-3.12，FAISS 不支持 3.13+

### Q2：Java 后端启动失败

**常见原因及解决：**
- MySQL 未启动 → `docker-compose up -d`
- 端口 8888 被占用 → 修改 `application.yml` 中的 `SERVER_PORT`
- 数据库连接失败 → 确认 MySQL 容器正常运行，检查密码是否为 `123456`

### Q3：App 无法连接服务器

**检查项：**
- Java 后端是否正常运行（访问 `http://localhost:8888` 无报错）
- 模拟器使用 `http://10.0.2.2:8888/`，真机使用电脑局域网 IP
- `build.gradle.kts` 中的 `BASE_URL` 是否配置正确
- 防火墙是否放行 8888 端口

### Q4：管理端页面空白

**常见原因及解决：**
- 未登录 → 先访问登录页
- Token 过期 → 清除浏览器 localStorage 后重新登录
- API 请求失败 → 打开浏览器 F12 控制台查看网络请求

### Q5：AI 回复很慢或无回复

**常见原因及解决：**
- Python 服务未启动 → 检查 `http://localhost:8000/docs` 是否可访问
- API Key 额度用尽 → 检查豆包账户余额
- 网络问题 → 确认服务器能访问豆包 API（`https://ark.cn-beijing.volces.com`）

### Q6：语音识别不准确

**说明：** 语音识别使用豆包多模态模型，非独立 ASR 服务。建议：
- 在安静环境录音
- 说话清晰、语速适中
- 录音后检查识别文字，确认无误再发送
